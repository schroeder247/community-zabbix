# SDK API reference

The public surface of the .NET SDK, generated from the source XML documentation: the contracts
(`Community.Zabbix.Abstractions`), the per-version API model (`Community.Zabbix.Api`), the server, clients and tree (`Community.Zabbix.Sdk`), the framed-TCP wire (`Community.Zabbix.Wire`), the agents, send loop and store (`Community.Zabbix.Agent`), the listeners, the passive agent and the proxies (`Community.Zabbix.Proxy`), the EF Core store
(`Community.Zabbix.Agent.Storage.EntityFrameworkCore`). Start at
[ZabbixClient](Community.Zabbix.ZabbixClient.yml).
