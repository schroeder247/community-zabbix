# Community Zabbix

A .NET SDK and PowerShell modules for Zabbix 7.0, 7.4, and 8.0. Manage Zabbix through its API, send and read monitoring data
over the Zabbix protocol, and run agents, proxies, and listeners inside your own applications and scripts.

- **Start here:** [the overview](README.md), [install](docs/INSTALL.md), and getting started with
  [.NET](docs/GETTING-STARTED.md) or [PowerShell](src/Zabbix.PowerShell/GETTING-STARTED.md).
- **Do something specific:** [the guides](docs/INDEX.md#guides) and [the samples](samples/README.md).
- **Fix something:** [troubleshooting](docs/TROUBLESHOOTING.md) and [known limitations](docs/KNOWN-LIMITATIONS.md).
- **Look something up:** [the .NET API reference](api/index.md) and the command reference for
  [Community.Zabbix](docs/reference/Community.Zabbix/README.md),
  [Community.Zabbix.Agent](docs/reference/Community.Zabbix.Agent/README.md), and
  [Community.Zabbix.Proxy](docs/reference/Community.Zabbix.Proxy/README.md).
- **About the project:** the [changelog](CHANGELOG.md), [security](SECURITY.md), and [contributing](CONTRIBUTING.md).
